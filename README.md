# 🎮 Jeux Brise-Glace

Plateforme de 37 jeux brise-glace pour animer vos événements, réunions et formations.

## 📖 Description

Cette plateforme web propose une collection de jeux interactifs conçus pour briser la glace et créer une ambiance conviviale lors d'événements de groupe.

## 🚀 Démarrage rapide

### Visualiser localement

Ouvrez simplement le fichier `index.html` dans votre navigateur, ou utilisez un serveur local :

```bash
# Avec Python
python3 -m http.server 8000

# Avec Node.js
npx http-server

# Avec PHP
php -S localhost:8000
```

Puis accédez à `http://localhost:8000`

## 🌐 Hébergement

Ce site est prêt à être hébergé sur plusieurs plateformes :

- **GitHub Pages** : Déploiement gratuit directement depuis GitHub
- **Netlify** : Configuration incluse dans `netlify.toml`
- **Vercel** : Configuration incluse dans `vercel.json`
- **Hébergement traditionnel** : Compatible Apache/Nginx

📚 **Consultez [HOSTING.md](HOSTING.md)** pour des instructions détaillées de déploiement.
